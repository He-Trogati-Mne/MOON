### Стек технологій

Проєкт написаний на чистому стеку без використання важких фреймворків:
* **HTML5** — семантична та чиста розмітка.
* **CSS3** — стилізація, Glassmorphism, анімації, Flexbox/Grid.
* **Vanilla JavaScript** — ініціалізація реального часу та лоадер.

---

### Як запропонувати зміни

| Крок | Дія | Опис |
| :---: | :--- | :--- |
| **1** | **Fork & Clone** | Зробіть форк репозиторію та клонуйте його собі на ПК. |
| **2** | **Branching** | Створіть нову гілку: `feature/назва` або `fix/назва`. |
| **3** | **Testing** | Внесіть зміни та обов'язково протестуйте їх локально у браузері. |
| **4** | **Commit** | Зробіть коміт із лаконічним описом (англійською або українською). |
| **5** | **Pull Request** | Надішліть PR у гілку `main` оригінального репозиторію. |

#### Приклад створення гілки у терміналі:
```bash
# Для нових фіч або анімацій
git checkout -b feature/cool-new-animation

# Для виправлення помилок або посилань
git checkout -b fix/broken-link
